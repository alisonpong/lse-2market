## 2Market - Customer Demographic and Advertising Channel Analysis
### LSE Data Analytics Accelerator Course Project
---
#### 🏥 Project Overview
2Market is a fictional global supermarket brand that hopes to learn about its customers' purchase behavior from its raw data. Specifically it wants to understand:
- Customer demographics
- Most effective advertising channels
- Most popular products and which segment is it most popular with

To support 2Market, an analysis was carried out in Python and a Power BI dashboard was created to include key metrics for decision-making
